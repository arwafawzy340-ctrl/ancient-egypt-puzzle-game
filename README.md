#  Ancient Egypt Puzzle Game

An interactive puzzle-adventure game inspired by Ancient Egyptian temples, developed as a solo project using Unity and C#.

## 🎮 Overview

The player explores a mysterious ancient temple filled with puzzles, traps, and hidden clues.

The game focuses on exploration and problem-solving, where the player must understand clues and interact with the environment to progress through the temple.

##  Key Features

* Ancient Egyptian-inspired temple environment
*  Interactive puzzle mechanics
*  Hieroglyph-inspired clues
*  Treasure chest trap
*  Falling-floor trap and environmental hazards
*  Player health and damage system
*  Checkpoints
* Final sequence

##  Technologies

* **Unity**
* **C#**
* **TextMeshPro**
* **Unity UI**
